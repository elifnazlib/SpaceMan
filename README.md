# SpaceMan

2D game I and my team created using Java and JavaFX.

In the game, you are an astronaut trying to reach the earth in a grid-based map full of obstacles and stars, using WASD keys.

<br>

Made for the term project of the course ```CMPE 114 - Fundamentals of Programming II```.

Developed in 2022.
